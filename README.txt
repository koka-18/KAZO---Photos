KAZO PHOTOS — SITE V1

CONTENU
- index.html : page du site
- css/style.css : mise en page et styles
- images/logo-kazo.svg : logo vectoriel inclus dans cette archive
- images/photo-01.svg à photo-06.svg : emplacements temporaires pour vos photographies

OUVRIR LE SITE
Double-cliquez sur index.html pour l'ouvrir dans votre navigateur. Les polices DM Sans et Playfair Display se chargent depuis Google Fonts si une connexion Internet est disponible.

AJOUTER VOS PHOTOGRAPHIES
1. Placez vos fichiers photo dans le dossier images.
2. Dans index.html, remplacez les chemins images/photo-01.svg, images/photo-02.svg, etc. par les noms de vos vrais fichiers, par exemple images/photo-01.jpg.
3. Remplacez aussi le texte alt par une description courte de chaque photographie.
4. Vous pouvez dupliquer ou supprimer des blocs <figure class="photo-card"> pour changer le nombre de photos affichées.

LIENS DES RESEAUX
Dans index.html, remplacez VOTRE_COMPTE par le nom de votre compte Instagram et VOTRE_PAGE par l'identifiant de votre page Facebook.

NOTES
- Le site est volontairement constitué uniquement de HTML et CSS, sans JavaScript.
- Les commandes sont prévues par message privé via Instagram ou Facebook ; il n'y a pas de panier ni de paiement intégré.
- Un filigrane visuel est affiché sur les photos, mais aucun site ne peut empêcher totalement les captures d'écran ou la copie des images affichées.
- Les images photo-01.svg à photo-06.svg sont de simples emplacements, pas vos photographies finales.
